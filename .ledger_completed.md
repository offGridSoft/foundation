# Foundation Completed Ledger

Status: Evidence inventory; not a declaration that the final API is complete

This ledger records work already present in Foundation. Items remain here only
when production code and direct tests demonstrate the capability. A completed
mechanism may still have pending naming, ownership, or public-surface work.

## Architecture and governance

- [x] Root `SPEC.md` defines the socket-and-plug model, struct-first contracts,
      interface discipline, stable intent surfaces, O(1) streaming,
      cross-platform behavior, testing, evolution, and the proposed probe.
- [x] `core/SPEC.md` defines the first package-local contract.
- [x] `_docs/governance/go_doctrine.md` defines compiler, context, time,
      concurrency, error, security, resilience, package, and shutdown doctrine.
- [x] `_docs/governance/testing_protocol.md` defines hostile boundary tables,
      red/green slices, layer triads, structural equality, error identity,
      goroutine ownership, fuzzing, streaming proof, and waiver rules.
- [x] Foundation admission requires a cross-product compiler-visible contract.
- [x] Historical releases, not compatibility shims in current code, are the
      compatibility boundary.

- [x] `NanosecondsDuration` represents a non-negative duration or budget with
      strict integer JSON.
- [x] `ByteCount` represents a required positive capacity or limit.
- [x] `ByteLength` represents an exact non-negative extent including zero.
- [x] Byte conversion to signed filesystem/stream sizes is checked.
- [x] `MoneyPennies` performs exact integer addition, subtraction, and quantity

- [x] Absolute file and directory paths are typed and lexically validated.
- [x] File and directory mode constants are compiler-owned.
- [x] Platforms, products, schemas, hashes, signatures, keys, storage
      providers, and request identities are typed.

## Temporal primitive candidate

- [x] `temporal/SPEC.md` resolves unset-zero behavior, closed ordering,
      arithmetic, JSON, humanization, persistence, error identity, complexity,
      cross-platform, export-budget, and hostile-proof contracts.
- [x] `Instant`, `Duration`, and `AggregateDuration` have private,
      proof-carrying representations with exact nanosecond truth.
- [x] Instant add/subtract/since, duration add/multiply, aggregate
      add/add-duration/multiply, and all three ordering surfaces use checked
      arithmetic and closed `Order` results.
- [x] Signed and unsigned 128-bit canonical JSON use decimal strings and reject
      malformed, non-canonical, JavaScript-lossy numeric, and overflow input
      without receiver mutation.
- [x] Humanization is integer-only, deterministic, exact-precision,
      byte-specified, and identical across ordinary/aggregate overlap.
- [x] Firestore and PostgreSQL projections preserve authoritative exact
      nanoseconds and validate native query timestamps as deliberately
      microsecond-truncated derived fields.
- [x] `core.ErrTemporalContract` wraps `core.ErrFoundationContract`; malformed
      decimal and overflow paths preserve their additional typed identities.
- [x] `public.go` centralizes package-level entry points; an AST ratchet pins
      every export, public field, entry-point location, and product-neutral
      dependency.
- [x] Hostile boundary tables, non-mutation tables, active parser fuzzing,
      race/shuffle repeats, static gates, native Darwin tests, and Linux/Windows
      cross-builds are green.
- [x] Temporal performs no I/O, clock observation, waiting, database import,
      goroutine creation, collection walk, or unbounded allocation.

- [x] Panic formatting remains contained even when a formatter itself panics.

## Current assessment

The substantial mechanical work is already present. The remaining work is not a
rewrite of fsync, retry, time, JSON, memory, or shutdown from scratch. It is the
intentional consolidation recorded in `.ledger_pending.md`: approve permanent
names, reduce exports, move misplaced ownership, close strict streaming and
fault-injection gaps, specify each package, and add conformance probes.

The storage inventory also proves one final primitive boundary. Existing
consumers already perform signed streaming upload and download through
`exchange`, while provider, URL, object, header, authorization, and receipt
facts are scattered. The bounded exchange stream is complete; the
provider-neutral `objectstore` ownership boundary is pending.
